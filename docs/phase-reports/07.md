## Decisions recorded

- `style-src 'unsafe-inline'` is decided, not open: `CoverImg.astro`
  `style={style}` + `render.ts` `style="background-color:…"` (hex validated
  by `DOMINANT_RE`) cannot be hashed; style cannot execute script. Scripts
  stay hash-only, never `'unsafe-inline'`.
- JSON-LD needed no hash: `type="application/ld+json"` is a non-executable
  data block — `script-src` does not apply (confirmed against current CSP
  behavior; the e2e violation listener is the tripwire either way).
- Middleware env access: `context.locals.runtime.env` is **removed** in the
  pinned Astro v6-era adapter (throws at runtime) — the sanctioned path is
  `getEnv()` from `src/lib/env.ts` (the repo's single `cloudflare:workers`
  reader). CSP degrades to self-only if env is unavailable.
- `healthz` uses the smallest real repository read
  (`listPublishedPosts(db, { locale: "en", limit: 1 }, now)`) — no new SQL
  dialect, no version strings, no env echo.
- No caching (spec 7.2 default): TTFB p95 42 ms home / 50 ms post (50
  samples each, local preview). Publishing stays instantly visible; no TTL
  ADR (spec requires one only if adopting).
- Retention is an age-based R2 bucket lifecycle rule (84-day expiry on prefix `backups/` ≈ 12 weekly backups), not per-run listing:
  wrangler 4.156.1 exposes no object-list query.
- `workers.dev` stays enabled; safety rests on Phase-4 JWT
  (host-independent, unit-covered). Disabling would kill preview URLs for
  zero security gain (ADR-006).
- New pins (exact, published ≤ 2026-11-03): `lighthouse@13.6.0`
  (2026-10-27), `@axe-core/playwright@4.14.0` (2026-10-15),
  `chrome-launcher@1.2.2` (2026-09-29). No new `allowBuilds` (JS-only).
- Lighthouse runs via `chrome-launcher` + bundled-flags API (v13):
  Playwright's Chromium (`chrome-linux/chrome` on CI runners,
  `CHROME_PATH` env). System Chrome 2026-era builds fail driver connect;
  Playwright Chromium works (100s recorded below).

## Bugs found by verification (fixed, not waived)

1. **Middleware 500 on every route**: `context.locals.runtime.env` throws (`removed in Astro v6`) — switched to `getEnv()`; CSP falls back to self-only outside the worker runtime.
2. **`healthz` 503**: `listPublishedPosts` requires `locale` — passed `{ locale: "en", limit: 1 }`.
3. **Lighthouse driver crash** (`this._page.target is not a function`): v13 API is `lighthouse(url, flags, config)` with an externally launched browser — rewrote via `chrome-launcher@1.2.2` + Playwright Chromium (`CHROME_PATH`).
4. **Audit script**: `.mjs` cannot carry TS `interface` syntax (stripped to JSDoc); allowlist URL resolved one level too high (`../`, not `../../`).
5. **Playwright project globs**: `admin-hardening.spec.ts` didn't match `**/admin.spec.ts` — widened to `**/admin*.spec.ts` in both `testMatch` and `testIgnore`.
6. **Admin 401 e2e untestable locally**: the dev bypass defeats the guard by design — 401s stay unit-covered (`auth.test.ts`); live proof is the post-deploy `workers.dev` curl in DEPLOYMENTS.md §6.5.
7. **Local D1 export**: miniflare cannot dump FTS5 virtual tables — table-scoped export documented as the local-proof path (remote needs no scoping).
8. **Local import FK order**: dump row order violates FK checks under `d1 execute --file` — per-table import in dependency order (`runbook.md` §2).
9. **Stray probe files** (`hz.json`, `home*.html`, screenshots) polluted `pnpm check`/git — removed/reverted; screenshots are capture-only noise.
10. **`.dev.vars` restore**: overwritten during admin e2e, restored with full local content (`ADMIN_DEV_BYPASS=1`, gitignored — never committed).

  (decided: `'unsafe-inline'` for style only — recorded above, no new

  `backups/gurat-YYYY-MM-DD.sql` (prefix disambiguates if the bucket ever

  5xx JSON line (`{rid, method, path, status, ms}`, no query/headers/
  identity) is the log; volume on a personal blog needs no sampling.

  middleware) — no exemption.
- `audit-allowlist.json` starts `[]`; any future HIGH/CRITICAL needs a
  documented entry or a fix (gate fails otherwise).
