## Bugs found by verification (fixed, not waived)

1. **Bitmap dimensions read after `close()`** (`src/islands/mediaClient.ts`): `bitmap.width/height` were read after `bitmap.close()`, yielding `sourceWidth: 0` → every browser upload 400'd. E2E caught it; fixed by snapshotting dimensions first. Unit tests can't cover this (no canvas in workerd) — covered by e2e + the intercepted-body probe.
2. **CSRF guard blocked multipart + empty-body DELETE**: `assertSameOrigin` required JSON `Content-Type`. New `assertSameOriginNoJson` (Origin + Sec-Fetch-Site) wired via `guard(..., { nonJson: true })` for the upload POST and media DELETE; unit-tested in `tests/auth.test.ts`.
3. **E2E selector collisions**: figure atoms carry `contenteditable=false` (matched the shared `.tiptap, [contenteditable]` selector → narrowed to `.tiptap`); toolbar button name is `aria-label` ("Insert image"), not content. Spec-only fixes.
