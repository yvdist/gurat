# Phase 3 report — Design implementation

Date: 2026-11-16. Status: complete.

## What shipped

Owner mockups (Home light, Post dark, Admin dashboard) implemented on the
Phase 2 reader. Admin dashboard PNG is Phase 4 input, not built here.

- `docs/design/spec.md`: verbatim transcription of the owner PNGs (Appendix A).
- ADR-003 (`docs/decisions/003-css.md`): plain CSS, no Tailwind; no syntax
  highlighting; no View Transitions.
- Self-hosted fonts (fontsource 5.3.0, ≤ 2026-11-01 cutoff): Bodoni Moda
  display (latin), Newsreader body (latin + latin-ext), IBM Plex Mono labels
  (latin). CJK accents use the system stack, never a webfont.
  `font-display: swap`; display face preloaded; total page JS 1,306 B (≤ 3 KB).
- Tokens (`tokens.css` is the sole home of design values; light `:root`,
  dark `[data-theme="dark"]`): theme resolution stored override → OS
  preference, no-flash script pre-paint (~230 B, CSP hash noted for Phase 7).
- Chrome: `Header` (brand + mono nav + en/id segmented + theme),
  `Footer` (hairline, © line, 余白, rss text), `ThemeToggle` (light/dark/auto,
  keyboard-operable, `aria-pressed`), `PostCard`, `Byline`, `PrevNext`,
  `Toc` (stored `toc_json`), `TagPill`. `ArticleBody` keeps the sole `set:html`.
- Post numbering: `getPostNo` / `getPostNos` (batched, no N+1) /
  `getAdjacentPosts` (same `publishedAt DESC, id ASC` ordering, reusing
  `visibilityFilter`), zero-padded 3. Prev/next links resolve 200 (e2e).
- New nodes (schema `.strict()` + renderer + tests, then `pnpm db:rerender`):
  `pullquote` → `figure.pullquote > blockquote`; `sidenote` (document-order
  `sn-{k}`, inline label span, right column ≥ 1280 px else inline marginal);
  `footnote` (collected once after last block as `section.footnotes`,
  `fn-{k}` + `↩` to `#fnref-{k}`; inline refs are author-paired sidenote
  links, renderer does not cross-validate). 9 new tests (accept/reject per
  node, 3 goldens, XSS label/caption, EN+ID parity). Rerender idempotent
  (6 rows byte-identical on re-run).
- Pages (EN + `/id/` mirrors): home (hero, Latest 3, Topics top-4 with fixed
  kanji map for the 4 seed slugs, Archive 5 + About card), post (breadcrumb,
  pills, lede, meta + translation link, hero panel, TOC/article/sidenotes
  grid, footnotes, byline, prev/next, copy-link with `aria-live`), archive /
  tag / about / 404. Empty states keep Phase 2 copy. About bio reuses
  `site.intro` (owner copy open, not invented).
- i18n: 21 new keys both locales, key-drift test green.
- Screenshots: `tests/e2e/visual.spec.ts` (capture-only) — 5 pages × 3 widths
  × 2 themes = 30 baselines committed.

## Verification

- `pnpm check` (astro 0 errors, biome clean, 45 vitest green) + `pnpm build`.
- Mobile Lighthouse (preview server, 3× post / 1× home): post perf 1.0,
  a11y 1.0, CLS 0.003–0.004 stable; home perf 0.99, a11y 1.0, SEO 1.0
  everywhere, CLS 0–0.048. The one 0.92/0.178 throttled run was a body-face
  swap reflowing the first article paragraph; fixed by preloading the
  Newsreader 400 woff2 alongside the display face (plan said display only —
  justified: body text is CLS-critical too; same-origin, no CSP change).
  Remaining perf notes are preview-server artifacts (no gzip in
  `astro preview`; Workers compresses).
- Accessibility 1.0 on home + post after two fixes: dark indigo lifted
  `#5b6fd6` → `#8494ee` (4.31:1 → 6.86:1 on `--bg`) and `min-height:
  --tap-min` (1.5rem) on nav links, segmented buttons, TOC links.
- Contrast pairs (computed): light ink 18.48 / muted 5.84 / indigo 8.96;
  dark ink 16.32 / muted 7.32 / indigo 6.86 — all ≥ AA 4.5. Dark indigo was
  lifted from the mock `#5b6fd6` (4.31:1, fails small-text AA) to `#8494ee`;
  decorative indigo unchanged.
- CSP note for Phase 7: two inline scripts (no-flash ~230 B + interactions
  ~1,076 B); hash both, no new CSP host (fonts same-origin `/_astro/`).
- No-regression greps: `set:html` only in `ArticleBody`; no `client:` islands;
  env isolation unchanged; no hard-coded design values outside `tokens.css`.
- States: draft/future 404 both locales (e2e); >150-char title renders in
  full (screenshots); missing translation falls back to home link (Phase 2
  behavior kept); 0-tag/empty-archive branches kept with Phase 2 copy.
