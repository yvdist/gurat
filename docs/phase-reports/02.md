# Phase 2 report — Content model and public reading

Branch `phase-2`. All five acceptance criteria pass (commands + pasted
evidence below). One baseline repair, no ADR (no locked decision changed).

## What was done

- **Baseline repair.** Workstation `core.autocrlf=true` with no `.gitattributes`
  checked out CRLF; Biome demands LF, so `pnpm check` failed on format-only
  (36 errors, lint clean, astro/vitest green). Fix: `.gitattributes`
  (`* text=auto eol=lf`) + renormalize. Zero blob changes. CI (LF checkout)
  was never affected.
- **Schema** (`src/lib/content/schema.ts`). Zod strict allowlist: `doc`,
  `paragraph`, headings 2–4, `blockquote`, both list kinds, `listItem`,
  `codeBlock`, `horizontalRule`, `hardBreak`, `figure`, `text`; marks `bold`,
  `italic`, `code`, `link`. Unknown nodes/marks/attrs rejected with zod
  path-aware errors (asserted on `issues[].path`). Extension point for
  `footnote`/`pullquote`/`callout` documented in a comment. (Zod 4 note:
  `discriminatedUnion` members must keep inferred literal types — annotating
  them as bare `z.ZodType` erases the discriminator and fails typecheck.)
- **Renderer** (`src/lib/content/render.ts`). Pure, no DOM/Node APIs. Escape by
  construction; links allow `http(s)`, `mailto`, relative (not `//`);
  absolute http(s) gets `rel="noopener noreferrer"`, no `target`. Anything
  else renders as plain text (no `<a>`). Headings slugified + deduped
  (`slug`, `slug-2`…), pushed to `toc`. Code language allowlisted
  (`/^[a-zA-Z0-9+-]{1,32}$/`). Figures look up `ctx.media`, throw on unknown
  `mediaId`; `variantUrl` is the Phase-2 placeholder (`/media/<id>/…`, no R2
  until Phase 5). Unknown node/mark at any depth throws `RenderError`
  (with content path). Reading time via `Intl.Segmenter(locale,
  word)`/`200 wpm`, min 1. The rerender + workerd vitest runs prove
  `Intl.Segmenter` word counts on the pinned runtime (EN and ID 400-word
  docs both → 2 min).
- **Seed + rerender.** `scripts/seed.ts` emits real allowlist docs per post
  (same 8 posts/IDs/slugs/groups/statuses; headings incl. duplicated text for
  `-2` dedup, full mark set, blockquote, both lists, codeBlock with language,
  rule). No figures (Phase-5 media). `scripts/rerender.ts` + `pnpm db:rerender`:
  dumps rows via the pinned local `wrangler` spawned through node (no PATH
  dependence — bare `wrangler` is unresolvable from child processes on some
  platforms), validates + renders, applies `UPDATE`s of `content_html`,
  `toc_json`, `reading_minutes` only via `--file`. Second run byte-identical
  (diff of full `content_html`/`toc_json`/`reading_minutes` dump empty).
- **i18n.** 10 new keys per locale (`site.intro`, nav ×3, reading time,
  translation link, writing/tags/about titles, 404 pair, `writing.next`,
  `nav.skip`, `nav.primary`); key-drift test still passes. `formatPostDate`
  via `Intl.DateTimeFormat(locale, { dateStyle: 'medium', timeZone:
  SITE.timezone })`; timezone-boundary test pins Jakarta behavior
  (2026-11-05T18:30Z → "Nov 6, 2026" EN / "6 Nov 2026" ID).
- **Shell.** `Base.astro` (lang, title, meta description, canonical, hreflang
  - `x-default` = EN URL, skip link, header/nav, main, footer, one `h1`),
    `ArticleBody` (the ONLY `set:html`, commented as safe: `renderDoc` output),
    `tokens.css`/`base.css`/`article.css` (system stack, ~65ch, light+dark,
    reduced-motion kill-switch; every placeholder `/* DESIGN: Phase 3 */`).
- **Routes.** EN + `/id/` mirrors: `/`, `/writing` (cursor archive grouped by
  year in SITE.timezone), `/writing/[slug]`, `/tags`, `/tags/[slug]`,
  `/about`, localized `404.astro` (locale from URL prefix). Missing/draft/
  future/wrong-locale → 404, never 403/redirect. Post page: `h1`,
  `<time datetime>` + formatted date, reading time from stored
  `reading_minutes`, tags, translation link or other-locale home fallback.
  `getEnv()` in pages; only `src/lib/env.ts` reads `cloudflare:workers`.
- **Middleware.** `nosniff`, `strict-origin-when-cross-origin`,
  `camera=(), microphone=(), geolocation=()`, `DENY`. No CSP (Phase 7).
- **Lint config.** `biome.json` → `biome.jsonc` (JSON cannot carry the
  rationale comment); `*.astro` override now also covers `noUnusedVariables`
  (same Biome blindness as `noUnusedImports`: frontmatter bindings consumed
  only by markup); per-line ignores for the intentional `!important`
  reduced-motion kill-switch.

## Deviations (plan guess → verified reality, no ADR: nothing locked changed)

1. Rerender spawns the pinned local `wrangler/bin/wrangler.js` via
   `process.execPath`, not bare `wrangler` (unresolvable from child
   processes on this platform). Same documented `d1 execute --json/--file`
   semantics; output shape handled for both single- and multi-batch JSON.
2. E2E `webServer` is `pnpm build && pnpm preview`, not `pnpm dev`: dev
   injects HMR `<script>` tags, so the 0-JS criterion can only be proven
   against the shipped output. Requires seeded local D1 first (documented
   in config + report).
3. D1 caps bound parameters per statement: route-test fixture inserts in
   batches of 4 (single 29-row multi-insert fails with `D1_ERROR: too many
   SQL variables`).
