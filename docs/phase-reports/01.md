# Phase 1 report — Foundation and data

Branch `phase-1`. All seven acceptance criteria pass (commands + pasted output
below). Deviations from the plan's guesses are documented in ADRs; in every
case the current official docs were followed over the plan.

## What was done

- **Scaffold.** Astro 7.4.4 + `@astrojs/cloudflare` 14.4.3, `output: 'server'`,
  `session: false`, TS strict, neutral placeholder `src/pages/index.astro`.
  `src/config/site.ts` holds the single `SITE` constant (name `Gurat`,
  placeholder URL, `en`/`id`, `Asia/Jakarta`).
- **Workers config.** `wrangler.jsonc`: `main` = adapter unified entrypoint,
  `assets: { directory: ./dist, binding: ASSETS }`, D1 `DB` (`gurat`,
  `d1ab1a16-…`), R2 `MEDIA` (declared, unused), `vars.SITE_URL`.
  `compatibility_date` = `2026-10-30` (see deviations).
- **Env isolation.** `src/lib/env.ts` is the only app reader of
  `cloudflare:workers`; repos take `D1Database`. Grep proof in acceptance table.
- **Tooling.** Biome (`recommended` preset) + ADR-001. `pnpm check` =
  `astro check` + `biome check .` + `vitest run`. Scripts use `pnpm exec`.
- **Schema + migrations.** Drizzle schema mirrors spec SQL (creation order,
  CHECKs, `UNIQUE(locale,slug)`, partial `posts_translation_unique`,
  `posts_feed_idx`, stated ON DELETE actions). Flat `migrations/*.sql`
  (drizzle-kit default; no `migrations_pattern` needed).
- **Repositories.** `visibilityFilter` once in `posts.ts`; cursor pagination
  (opaque base64url, limit clamp 1–50); `getPublishedPostBySlug` (+tags,
  +alternates); `getTranslations`; `listTags` (visible-only counts); admin
  `NotImplementedError` stubs. Bound parameters only; workerd-safe cursor codec
  (no `Buffer`).
- **Seed.** `scripts/seed.ts` emits idempotent SQL applied via
  `wrangler d1 execute --local`: 4 tags, 6 posts (3 EN/3 ID, pairs
  `group-hello`/`group-second`), 1 draft, 1 future (`now+7d`), 1 title >150
  chars. Fails loudly on unique-violation.
- **i18n.** `en.json`/`id.json` (same 4 keys), `t`/`localizePath`/
  `detectLocaleFromPath`/`alternatesFor`; test fails on key drift.
- **Tests.** Vitest via `@cloudflare/vitest-plugin` against real local D1
  (no mocks): draft/future exclusion, pagination stability across inserts,
  both uniqueness constraints, tags+alternates. Playwright smoke (`/` 200).
- **CI/docs.** `.github/workflows/ci.yml` (frozen lockfile, check, build, no
  deploy), `README.md`, `AGENTS.md`, ADRs 001–002.

## Deviations (plan guess → doc-verified reality, see ADR-002)

1. Env API is `import { env } from "cloudflare:workers"`, not
   `locals`/`getPlatformProxy`. Test package is `@cloudflare/vitest-plugin`
   (not `…/vitest-pool-workers`), needs Vitest ≥ 4.1.
2. No `not_found_handling: 'single-page-app'` (SPA-only); default
   worker-fallback routing per the Astro deploy guide. `imageService:
   "passthrough"` avoids auto-provisioning IMAGES; `session: false` avoids
   session KV.
3. `compatibility_date` = `2026-10-30`, not scaffold day: the pinned workerd
   (miniflare Oct-23 bundle) supports max `2026-10-30`; scaffold day breaks
   the test runtime. Revisit when the test stack is re-pinned.
4. `@cloudflare/vite-plugin` override-pinned to 1.66.0 in
   `pnpm-workspace.yaml`: the adapter's `^1.63.1` range floats to 1.69.x,
   whose peer wants wrangler `^4.160` (past the ≥2-week cutoff).
5. pnpm 12 ignores a `pnpm` field in `package.json`; `allowBuilds` (esbuild,
   workerd) + `overrides` live in `pnpm-workspace.yaml`.
6. Flat migration layout (drizzle-kit default `migrations/*.sql`), so no
   `migrations_pattern`. Seed goes through `wrangler d1 execute --file`
   (stdin `--file -` EPIPEs; local D1 file is hash-named — never guess it).
7. `vitest.config.ts` excludes `tests/e2e/**` (Playwright must run under
   node, not workerd). Biome `*.astro` override for `noUnusedImports`
   (Biome can't see frontmatter use in markup).
