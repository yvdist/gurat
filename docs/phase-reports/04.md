# Phase 4 report — Admin and editor

Date: 2026-11-17. Branch: `phase-4`. Spec: `spec/04-admin-and-editor.md`.

## What landed

Owner signs in via Cloudflare Access, writes/saves-previews/publishes/
unpublishes posts in EN+ID from a browser. Content saved as Tiptap JSON,
server-rendered to HTML once at save time.

- **Auth** (`src/server/auth/access.ts`): `verifyAccess` (dev bypass →
  header → JWKS → iss/aud/exp → allowlist), `requireAdminPage` (302 login /
  403 text), `requireAdminApi` (JSON 401/403), `assertSameOrigin` CSRF.
  No other module reads the header. JWKS cached per team, 6 h TTL, kid-miss
  refetch via `jose`.
- **DB** (`src/server/db/admin.ts`, `tags.ts`): create/save/publish/
  unpublish/delete + by-id fetch; `ConcurrencyError`, `SlugConflictError`,
  `PublishValidationError`, `TagInUseError`, `NotFoundError`. D1-native
  `db.batch` (the workerd test isolate rejects BEGIN/COMMIT).
- **API** (`src/pages/admin/api/*` + `src/server/admin/service.ts`):
  save flow = parse → validateDoc (422 + path) → renderDoc (422 + path) →
  persist; 409 slug/concurrency (with live stamp), 422 validation/media,
  409 tag-in-use. Tags page uses server-rendered forms calling the same
  service (zero client JS) with an Origin check (Access cookie is
  ambient-auth, so form posts get the same CSRF rule as the JSON API).
- **Pages**: `Admin` layout (sidebar per owner decision — posts table only,
  no stat cards), dashboard (filters + continue-writing), new/edit (metadata
  panel + `EditorIsland client:only="svelte"`), preview (public `Base` +
  `ArticleBody` + `Toc`, `noindex`), tags. `robots.txt` gains
  `Disallow: /admin`.
- **Editor** (`src/islands/`): Tiptap core-mounted; custom nodes
  sidenote/footnote/pullquote/figure (insert disabled for figure);
  `editorDoc.ts` strips Tiptap noise (target/rel/class, unknown marks,
  bad hrefs — text kept). Toolbar labelled + keyboard-operable, focus
  visible, focus-mode, live words/minutes (`Intl.Segmenter/200`, same as
  renderer). Autosave 2 s debounce, saved/saving/offline/conflict,
  beforeunload guard, reload/overwrite panel; publish validates;
  slug autofill, published-slug warning, translation create/link panel.
- **ADR-004**: `svelte@5.57.3`, `@astrojs/svelte@9.1.2`,
  `@tiptap/{core,starter-kit,extension-link}@3.32.2`, `jose@6.2.14`.

## Notes

- E2E runs against `astro dev` (:4322, separate `admin` Playwright project)
  because the bypass is dead in production builds by design; `.dev.vars`
  needs `ADMIN_DEV_BYPASS=1` + `ADMIN_EMAILS` + `SITE_URL=http://localhost:4322`
  (CSRF requires Origin === SITE_URL). Spec probes the bypass and skips
  cleanly when inactive.
- `db.batch` replaces transactions: D1-native and test-isolate compatible.
- `biome.jsonc` override extends the `.astro` unused-vars exception to
  `*.svelte` (runes consumed only by the template).
